# DaoPeak

DaoPeak leverages low-latency architecture, high-throughput processing, and auto-scaling capabilities to orchestrate real-time data streams.

With DaoPeak, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/DaoPeak.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

DaoPeak is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
